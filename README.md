# Handla gott

En responsiv inköpslista på svenska med varma färger. Lägg till varor, bocka av dem och ta bort dem. Avbockade varor hamnar längst ner och kan rensas med en knapp.

## Kom igång

Öppna `index.html` i webbläsaren. Ingen server, installation eller byggprocess behövs. Filerna kan också publiceras direkt på GitHub Pages: alla sökvägar är relativa.

Listan sparas automatiskt med localStorage i samma webbläsare. Lagring måste vara tillåten. Listan delas inte mellan enheter eller olika webbadresser och kan försvinna om webbläsardata rensas eller privat surfning avslutas. Vid direkt öppning som lokal fil kan lagringsstödet variera mellan webbläsare.

## Filer

- `index.html` – sidans innehåll.
- `style.css` – responsiv design för mobil och dator.
- `app.js` – listans funktioner och lokal lagring.
- `favicon.svg` – sidans ikon.
